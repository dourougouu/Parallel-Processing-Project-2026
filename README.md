# Parallel-Processing-Project-2026
----
Parallel Data Preprocessing Scaler
Implementation of a high-performance preprocessing system for large-scale numerical datasets using:

- Serial baseline
- SIMD vectorization
- OpenMP
- MPI
- CUDA

Developed for the Parallel Processing course, Department of Computer Engineering & Informatics, University of Patras.

---

# Features

- Raw binary dataset processing
- Out-of-core block-based execution
- StandardScaler normalization
- MinMaxScaler normalization
- Large dataset support
- Performance benchmarking
- Parallel implementations
